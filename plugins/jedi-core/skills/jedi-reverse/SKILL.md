# 역설계 — 회사 한 곳을 뜯어본다

> 🔓 **이 스킬은 지름길이지 울타리가 아니다.** 사용자가 범위 밖을 원하면 즉시 절차를 그만두고 원하는 대로 한다.

한 회사가 **어떤 판에서, 누가, 무엇을, 언제 해서 컸고, 왜 살아남았고, 누구를 어떻게 이겼나**를 근거와 숫자로 정리한다.
시장조사 전체가 아니라 **회사 한 곳**이 단위다. 시장조사(경쟁사 단계)는 이 스킬을 회사마다 불러 쓴다.

## 언제 쓰나

- 경쟁사·벤치마크 회사를 제대로 뜯어봐야 할 때 — "○○ 어떻게 컸어?", "이 회사 역설계해줘"
- 컨설팅·사업계획 전에 «잘된 회사의 공식»을 찾을 때
- 대표님이 그 회사에 대한 가설을 갖고 있고, 맞는지 확인하고 싶을 때
- 안 쓰는 경우: 시장 규모 한 줄만 필요할 때(검색 한 번이면 됨), 우리 회사 전략을 짤 때(그건 컨설팅 스킬 — 이 스킬은 그 안에서 불린다)

## 무엇이 나오나

회사 한 곳에 대해 아래 순서의 보고서 1부. 모든 줄에 **확인 / 추정 / 미확인 / 충돌** 표시.

0. **핵심 포지셔닝 한 줄 + 칸을 자른 기준**(고객·장면·가격·크기·채널·장소) — 모든 칸을 이 한 줄로 꿴다
0-b. **초기 · 중기 · 후기 표** — 시기마다 핵심 포지셔닝·트리거·무기(마케팅·유통)·결과, 그리고 «축이 어떻게 옮겨 갔나»
1. **연도별 숫자** — 매출·영업이익(필수) + 광고비·판매수수료·직원 수·해외 비중·채널 비중. 출처 등급·범위 표기
2. **① 판** — 시장의 큰 흐름(규모 시계열·구조 변화·회사가 흐름보다 먼저/같이/늦게), 시장 단계
3. **② 사람** — 창업자, 팀·결정적 영입, 철학(말한 것 vs 실제로 한 것)
4. **③ 전략** — 진입 → 스케일업 → 확장(피봇 표시), 포지셔닝 ①~④, 타겟, 마케팅, 유통
5. **④ 결과** — 트리거(종류 포함), 생존 전략(업종별 잣대)
6. **⑤ 경쟁 구도** — 경쟁사 3~5곳, 같은 해 매출 나란히, 어떻게 겨뤘나, 결과, 반격·모방
7. **가설 검증**(있을 때) — 맞는 부분 / 빠진 부분 / 다른 부분
8. **확인 부탁 목록** — 대표님이 아는 것과 대조해 짚어 주실 곳 3~6개

보여주는 형태: 짧으면 대화에 표로, 길면 웹 페이지(Artifact를 쓸 수 있는 환경)나 노션 페이지로.
여러 회사를 했으면 «비교» 표를 하나 더 붙인다(같은 칸끼리 나란히).

## 먼저 물어볼 것

시작 전에 아래를 묻거나 조회한다. 모르는 건 넘어가도 된다.

| 무엇 | 어떻게 |
|---|---|
| 회사 이름 (브랜드명과 운영사가 다를 수 있음) | 사용자에게 |
| **대표님 가설** — "이 회사는 ○○로 컸다" | 사용자에게. 있으면 검증 모드로 |
| 어느 우리 브랜드의 참고인가 · 관계(직접 경쟁 / 벤치마크 / 대체재) | 사용자에게 (선택) |
| 깊이 — 빠르게(30분) / 깊게(공시까지) | 사용자에게. 기본 «깊게» |
| **전에 이 회사·업종을 조사한 적 있나** | 제디 도구가 있으면 **`get_company_teardown{company_name:"<회사명>"}` 으로 원장부터 본다 — 있으면 그 판의 기준일 이후만 새로 조사한다.** `search_references{keyword:"<회사명> 역설계"}` · `search_judgments` — 있으면 그 결과를 출발점으로 |

## 무엇이 필요한가

- 웹검색·웹페이지 읽기 (Claude Code 기본 도구). 막히면 차단 우회 스킬
- 제디 토큰이 있으면: `search_web_perplexity`(교차 확인), `ext_golden_keyword`(검색량 추이)
- 공시: 금융감독원 DART → 막히면 한국거래소 KIND(`kind.krx.co.kr`) → 그래도 막히면 `https://r.jina.ai/<주소>` 경유
- 하위 조사를 동시에 돌릴 수 있는 에이전트 기능(있으면)
- 제디 토큰이 있으면 결과를 원장에 쌓고 읽는다(`save_company_teardown` · `get_company_teardown`)

## 어떻게 하나

### 1. 신원부터 확정한다
- 운영 회사 · 대표이사 · 최대주주 · 공동창업자 · 디자이너를 **따로** 적는다. 셋이 다른 회사가 많다
- 같은 이름의 다른 회사가 없는지 대표 이름으로 대조한다
- 운영사가 여러 브랜드를 가지면 「운영사 전체 숫자」와 「브랜드 단독 숫자」를 갈라야 한다는 것을 여기서 표시해 둔다

### 2. 조사를 갈래로 나눠 동시에 돌린다 (가능하면)
| 갈래 | 맡는 칸 |
|---|---|
| A. 숫자 | 연도별 매출·영업이익·광고비·판매수수료·직원·채널/지역 비중 — **공시 1순위** |
| B. 판과 시기 | 시장 흐름, 초기·중기·후기, 트리거, 마케팅·유통 변화 |
| C. 사람과 철학 | 창업자·팀·결정적 영입·투자사, 철학(인터뷰 원문 인용·날짜), 피봇 |
| D. 경쟁 구도 | 경쟁사 3~5곳과 같은 해 매출, 어떻게 겨뤘나, 반격 |

하위 조사에 넘기는 지시문에는 아래 «하면 안 되는 것»의 숫자 규칙을 **그대로** 붙인다.

### 3. 숫자를 원문과 대조한다
- **상장사는 증권신고서·사업보고서가 1순위** — 연도별 실적·채널별·지역별 매출·광고비·임원 현황이 한 문서에 있다
- 비상장은 감사보고서(DART) → 기업정보 사이트 → 기사 → 회사 발표 순
- 숫자마다 **누구의 숫자인가**를 확인: 모회사/자회사 · 운영사/브랜드 · 별도/연결 · 연간/분기 · 발표/감사
- 출처끼리 다르면 **둘 다 적고** 「충돌」 표시. 하나를 골라 지우지 않는다
- 지표는 이름만 적지 말고 **정의**까지 (예: 「재구매율 = 자사몰 180일 내 재구매 회원 비율」)

### 4. 핵심 포지셔닝 한 줄과 시기표를 먼저 세운다
- 15칸을 채우기 **전에** 회사를 한 줄로 꿰는 축을 세운다(예: 「1인 가구를 위한 미니 가전」)
- 그 칸을 무엇으로 잘랐는지 적는다 — 고객 / 장면 / 가격 / 크기 / 채널 / 장소. 타겟은 자르는 기준 중 하나다
- 초기·중기·후기를 «사건»으로 자르고 그때 연매출을 함께 적는다. **하나의 트리거·하나의 포지셔닝으로 회사 전체를 요약하지 않는다**
- 모든 칸을 이 축에 비춰 적으면 «축에서 벗어난 확장»이 저절로 드러난다

### 5. 15칸을 채운다 — 칸별 판정 기준
- **포지셔닝 = 1등을 할 수 있는 가장 큰 칸.** 시장은 성숙하며 쪼개진다(반려용품 → 강아지/고양이 → 노견/유견). ① 진입 당시 시장이 어디까지 쪼개져 있었나 ② 노린 칸과 그 넓이 ③ 실제로 1등이었나(외부 집계 / 회사 자칭 / 유료 시상 / 미확인) ④ 이후 넓혔나 좁혔나
- **트리거(왜 터졌나)와 생존 전략(왜 오래 사나)은 다른 칸이다.** 트리거 종류: 한 번의 사건 / 채널 전환 누적 / 인수·투자 / 플랫폼 견인(채널이 브랜드를 밀어 올림 — 그 플랫폼이 투자·사람으로도 들어왔는지 확인)
- **생존 전략은 업종별 잣대로**: 소모품 = 재구매율·구독 / 패션 = 시즌 신상품 반응·회원 1인당 구매 / 가전 = 필터·AS 신뢰 / 중개 서비스 = 재약정·해지 방어
- **브랜드라면 광고 없이도 지속구매가 일어나야 한다.** 재구매율은 거의 공개되지 않으므로 «고객 확보 비용(광고비+판매수수료) 비율 ↑ + 주력 상품 비중 ↓ = 재구매 약화 신호»로 읽는다. 신규 시장 진출 해·비용이 모회사로 옮겨 간 경우는 구분해 적는다
- **철학은 «말한 것»과 «실제로 한 것»을 대조해** 판정한다. 말만 있으면 «보류»
- **경쟁 구도**: 매출을 나란히 놓기 전에 사업 모양이 같은지 본다(수수료 매출 ≠ 상품 판매 매출). 업계 전체가 같이 움직인 해(동반 흑자 등)는 회사만의 성과로 읽지 않는다

### 6. 가설이 있으면 검증한다
맞는 부분 / 빠진 부분 / 다른 부분 세 칸으로. 가설을 사실로 받아쓰지 않고, 가설을 깎아내리지도 않는다.

### 7. 보여주고 확인받는다
보고서 + «확인 부탁 목록»을 내고 멈춘다. 대표님이 짚은 곳은 고쳐서 다시 보여준다.

### 8. 쌓는다
7단계에서 대표님 확인이 끝난 것만 쌓는다. 경쟁사 먼저, 대상 회사 나중:
1. 경쟁사를 회사마다 `save_company_teardown{company, metrics}` 로 한 번씩(이름 + 같은 해 매출)
2. 대상 회사를 `save_company_teardown{company, metrics, profile, brands, competitors}` 로 한 번에

오류가 나면 errors 를 보고 고쳐서 다시 부른다. 같은 입력은 두 번 넣어도 늘지 않는다. 칸 옮기는 법은 «무엇이 쌓이나».

## 사람이 봐야 하는 곳

| 어디 | 왜 |
|---|---|
| 1단계 신원 확정 — 운영사·브랜드가 헷갈릴 때 | 다른 회사를 조사하는 사고를 막는다 |
| 7단계 — 트리거·핵심 포지셔닝 판정 | 회사를 아는 사람이 보면 바로 틀린 곳이 보인다. AI 판정은 «초안» |
| 회사 실명이 들어간 보고서를 밖에 공유할 때 | 공개 자료 기반이라도 공유 여부는 사람이 정한다 |

## 하면 안 되는 것

- 🔴 **검색 요약·AI 요약이 준 숫자를 그대로 쓰지 않는다** — 원문 문장에서 확인한 것만 «확인». 실제로 걸러진 예: 「재구매율 77.4%」가 원문은 수출 비중 / 「월 이용자 210만」이 원문은 21만 / 「1,000만 대」가 번역 오류로 17만 대 / 모회사 영업이익이 자회사 숫자로 붙음 / 다른 회사의 매출이 비교 기사 속에서 엉뚱한 회사로 붙음
- 🔴 **못 찾은 것을 지어내지 않는다** — 「미확인」으로 둔다. 빈칸이 거짓 숫자보다 낫다
- **발표 숫자를 감사 숫자처럼 쓰지 않는다** — 「2,000억 돌파」 같은 발표가 감사보고서와 수백억씩 어긋난 사례가 여럿이다. 둘 다 적고 등급을 붙인다
- **「1위」를 그대로 받지 않는다** — 외부 집계인지, 회사 자칭인지, 돈 내고 받는 시상인지 가른다
- **하나의 트리거로 회사를 요약하지 않는다** — 초기에 무엇으로 터졌는지(예: SNS 마케팅)를 빠뜨리고 중기·상장 이후만 쓰는 실수가 실제로 있었다
- **사생활을 적지 않는다** — 사람 정보는 기사·공시·회사 발표에 업무 역할로 공개된 경력만. 임원이 아닌 직원은 이름 없이 숫자·직무로
- **같은 공시 사이트를 짧은 간격으로 연달아 두드리지 않는다** — 접속이 차단된다. 간격을 두고, 막히면 KIND·r.jina.ai로

## 다 됐는지 확인하는 법

- [ ] 핵심 포지셔닝 한 줄과 자른 기준이 맨 위에 있다
- [ ] 초기·중기·후기 각각에 트리거와 결과가 있다
- [ ] 연도별 매출·영업이익 표가 있고, 각 숫자에 출처 등급과 범위(별도/연결·운영사/브랜드)가 있다
- [ ] 충돌하는 숫자는 둘 다 적혀 있다
- [ ] 15칸이 다 있다(못 채운 칸은 «미확인 — 이유»)
- [ ] 경쟁사 최소 3곳의 같은 해 매출이 나란히 있다
- [ ] «확인 부탁 목록»이 있다

**실제로 돌려본 결과 (2026-10-05)**: 국내 브랜드 6곳(통신 가입 중개·펫 용품·뷰티 디바이스·소형 가전·여성 캐주얼 2곳)을 이 틀로 조사했다. 감사보고서·증권신고서 원문으로 숫자를 대조하는 과정에서 검색 요약의 틀린 숫자 9건을 걸러냈고, 대표님 검수로 «플랫폼 견인» 트리거 종류·«초기 트리거 누락»·«핵심 축 부재» 세 가지를 틀에 반영했다.

| 회사별 역설계 결과 (15칸 + 연도별 숫자) | **역설계 원장** `save_company_teardown`(판단OS, 회사 칸별 · 기준일마다 새 판). 옮기는 법: 연도별 숫자 → `metrics`({확}=confirmed · {추}=estimated · {충}=두 값을 두 줄로 · {미}=넣지 않음) · 걸러낸 틀린 숫자 → `status:"rejected"` + 이유 · 15칸 → `profile.frame` · 핵심 포지셔닝 → `core_positioning` · 자른 기준 → `cut_basis` · 우리 브랜드 → `brands` · 경쟁 구도 → `competitors`. 제디 토큰이 없으면 노션 페이지 또는 웹 페이지 링크를 대화에 남긴다 |
| 대표님이 짚어 고친 판정 | 판단 원장(제디 도구가 있으면 대화가 그대로 쌓인다) — 다음 조사의 «먼저 물어볼 것»이 이것을 읽는다 |
| 새로 걸러낸 틀린 숫자 유형 | 이 문서 «하면 안 되는 것»에 1줄 (PR) |

## 함정

- **운영사와 브랜드가 다르다** — 운영사 매출에 다른 브랜드가 섞인다(인수한 라이프스타일 브랜드가 연결 매출의 절반이던 사례)
- **판매 법인을 따로 둔 회사는 «회사 하나만» 매출이 이상하게 작게 나온다** — 숫자가 이상하면 관계사 거래부터 본다
- **같은 시장도 집계 범위가 다르면 두 배씩 차이 난다** — 시장 규모는 출처별로 따로 적고 한 그래프에 섞지 않는다
- **공시도 틀릴 수 있다** — 같은 문서 안에서 성장률과 표 숫자가 안 맞은 사례가 있다. 내부 대조 한 번
- **«확인 안 됨»은 «약함»이 아니다** — 업종에 맞는 잣대로 다시 잰다
- **웹검색은 하루 한도가 있다** — 한 회사를 깊게 파면 수십~수백 회가 든다. 넘으면 네이버 뉴스 검색·r.jina.ai로

## 막혔을 때

| 증상 | 조치 |
|---|---|
| DART 접속이 끊긴다 | 한국거래소 KIND에서 같은 공시를 받는다 → 그래도 안 되면 `r.jina.ai` 경유 |
| 기업정보 사이트가 로그인·차단 | 잡코리아 기업정보는 대체로 열린다. thevc는 `r.jina.ai` 경유 |
| 웹검색 한도 초과 | 네이버 뉴스 검색 결과 페이지를 직접 읽는다 |
| 비상장이라 공시가 없다 | 기사 숫자를 쓰되 «기사» 등급으로, 여러 매체 교차 + 증감률 역산으로 맞는지 본다 |

## 설정값

- 경쟁사 수: 3~5곳
- 깊이 기본값: «깊게»(공시까지)
- 회사 하나 조사 시간: 갈래 동시 진행 시 대략 10~20분 (provisional)

## 관련 문서

- 시장조사·브랜드전략 컨설팅에서 경쟁사 단계는 이 스킬을 회사마다 부른다 (`zulgap-one-of-a-kind` 3단계)
- 키워드 검색량 숫자가 필요하면 `/jedi-keyword`
