# 시작 — 이전 맥락을 찾아 잇는다

> 🔓 **이 스킬은 지름길이지 울타리가 아니다.** 범위 밖을 요청받으면 즉시 이 절차를 그만두고 도구를 직접 부른다.

## 언제 쓰나
일을 시작할 때 팀팩을 쓰는 사람 누구나(직원·고객사). 무엇부터 할지, 어디까지 했는지를 찾아 잇는다. 감시·상태 확인은 서버가 따로 돌고 손쓸 일만 업무요청으로 올라오므로 여기서 다시 판정하지 않는다.

## 무엇이 나오나
15줄 안팎의 답 하나 — 이어서 할 일 · 손쓸 것 · 감시 한 줄. 파일·원장을 고치지 않는다(지난 실수 판단 올리기 제외).

## 먼저 물어볼 것
없음 — 묻지 않고 바로 조회한다. 후보가 여럿이고 단서가 없을 때만 고르시게 한다.

## 어떻게 하나 — 한 메시지에 병렬로

**PC 명령 2개** (`<이 스킬 폴더>` = 이 문서 맨 위 Base directory)
```bash
node "<이 스킬 폴더>/start-brief.js" --hint "<말씀·인자>"
f="$HOME/.claude/zulgap/onboard-check.js"; [ -f "$f" ] && node "$f" --json --no-report
```
**서버 도구 5개** — 회사 번호를 넣지 않는다(토큰 기준 자동. 관리자만 `read_tenant_id` 로 회사를 고른다)
- `get_reply_queue({status:"open", limit:30})` — 내 일
- `get_project_progress({})` — `unassigned`·`deal_candidates` 만 읽는다
- `get_shipments({mine:true})` — 내 진행 중 선적
- `get_company_context({mistakes:true})` — 판단으로 안 남은 실수
- `get_watch_summary({})` — 감시 한 줄

도구가 하나도 안 보이면 `jedi` 로 도구를 한 번 검색한다(처음엔 이름만 있는 상태일 수 있다). 그래도 0건일 때만 「제디 도구가 연결되지 않았습니다. 관리자에게 토큰을 받아 설치를 다시 실행해 주세요.」 🔴 못 읽은 도구를 「0건」으로 말하지 않는다 — 그 줄만 뺀다.

### 이어서 할 일 고르기 (위에서부터 · 아래로 갈수록 약하다)

| 순위 | 근거 | 이유 |
|---|---|---|
| 1 | `/시작` 인자에 붙은 핸드오프 경로 | `/jedi-save` 결과가 붙은 것 = 같은 창의 연속 |
| 2 | 말씀의 단서(도구의 ★) | 최신 의도 |
| 3 | 오늘 끊긴 흔적의 작업 폴더 일치 | 같은 창은 보통 같은 폴더 |
| 4 | 파일 날짜 | 🔴 단독 근거 금지 — 「다른 창 것일 수 있습니다」를 붙인다 |

- 단서가 없으면 후보를 최대 5줄 보여 드리고 고르시게 한다. 🔴 임의로 하나를 골라 시작하지 않는다.
- 후보 0건이면 `recall_prompts({query:"미해결 다음에 이어서 할 것 남은 작업", source:"journal", limit:5})` 의 `## 미해결 · 다음` ⬜ 줄에서 뽑는다(의미 검색이라 최신순이 아니다 — 날짜순으로 세운다). 그것도 0건이면 「아직 저장된 작업 기록이 없습니다. 일을 마칠 때 /jedi-save 로 저장해 두면 다음부터 여기서 이어집니다.」
- 도구가 낸 `작성자` 가 나와 다르면 1순위에서 내리고 「⚠ <작성자>님 파일 — 이 PC에서 다른 분이 쓴 것」을 붙인다.
- `소속` 줄은 보여 주기만 한다(고치는 곳은 `/jedi-save` 한 곳).
- 「끊겼어」「아까 하던 거」이거나 오늘 끊긴 흔적이 있으면 → `references/full-check.md` § 0번만 읽고 복구한다. 먼저 「이런 상태였습니다」를 보고하고 이어서 할지 여쭌다. 바로 파일을 고치지 않는다.

### 답 모양 (이 틀 그대로 · 15줄 안팎)

```
**이어서 할 일** — 11/4 카드 명세서 대조 (이 창 직전)
  남은 것: 국민은행 한 달
  이어서 할까요?

**손쓸 것**
📌 WR-ZG-2026-1103-18 네이버 블로그 재발행 · 기한 11/5
   …외 1건
📌 프로젝트 미정 3건 (기한 지남 1) — 미니앱 할 일 탭에서 정리
📁 «대륙유통 2단계 용역» 계약 — 프로젝트로 관리할까요?
🚢 진행 중 선적 2건 — 에이엔에너지 부킹(마감 D-2) · 판정 안 한 날짜 후보 3개

🛡 감시 1개 · 열린 이상 0건 · 감시 정상
```

**하드 리밋**: 할 일 5줄 · 후보 5줄 · 계약 후보 3줄 · 선적 3건 · 전체 15줄 안팎. 넘으면 「…외 N건」(조용히 자르지 않는다).

- **내 일**: `<code> 제목 · 기한 <due_at>` — 기한 빠른 순. 본인 일을 더 물으면 `jedi-work` 스킬을 부른다(절차를 여기 다시 적지 않는다).
- **프로젝트 미정**: `unassigned.count` 0 이면 줄 없음 · 숫자는 응답 그대로 · 목록을 펼치지 않는다. 「정리해줘」 하면 한 건씩 여쭙고 `set_work_request_project`.
- **계약 후보**: `deal_candidates.count` 0 이면 줄 없음(null 이면 「못 읽음」 — 0건으로 말하지 않는다). 있으면 계약마다 `📁 «<name>» 계약 — 프로젝트로 관리할까요?` (최대 3줄 · 계약된 지 14일 안인데 프로젝트가 없는 것 · 서버가 내 담당 섹션 것만 준다). 「응」이면 `save_project_plan`(how=shipment → `target_shipment_id`=shipment_ids[0] · how=deal → `target_deal_id`=deal_id · 섹션 = project_id · 단계는 여쭤서) 미리보기 → 「응」 → 확정. 「아니」면 그대로 둔다(14일 뒤 저절로 빠진다). 🔴 혼자 만들지 않는다 · 반복 운영 일은 만들지 않는다.
- **선적**: 응답에 `mine:true` 가 없으면 옛 서버 응답이다 — 줄 없음. `count` 0 이면 줄 없음. `slack_days` 작은 순 · 후보를 여기서 판정하지 않는다.
- **감시 줄**: `watchers` 가 있으면 `line` 을 그대로 쓴다(다시 판정하지 않는다 · 덧붙이지 않는다). 비어 있으면 줄 없음 — 이 회사엔 아직 감시가 안 돈다.
- **설치**: `"ready":false` 면 맨 위에 그 파일을 `--no-report` 로 돌려 나온 꼭 필요한 항목 **하나**의 3줄 + 「이것만 남았습니다. 같이 할까요?」. 선택 항목(`"required":false`)은 먼저 꺼내지 않는다. 출력 없음·오류는 말하지 않는다.
- **실수**: `unsaved_mistakes` 1건 이상이면 다음에도 쓸 교훈만 `save_tool_guidance`(text = 교훈 한 줄 · source_utterance = `said` 원문 · match_words 2~5개 · scope `"company"`) 뒤 「지난 실수 N건을 판단으로 올렸습니다 — <교훈>… · 틀리면 「빼」」. 교훈 없는 것·`said` 에 없는 말은 올리지 않는다. `pending_proposals`(관리자)는 한 줄씩 「응 / 고쳐서 / 아니」를 여쭙는다.

**좋은 예 / 나쁜 예**
- ✅ `이어서 할 일 — 어제 멈춘 카드 명세서 대조 (이 창 직전). 남은 것: 국민은행 한 달. 이어서 할까요?`
- ❌ `핸드오프 44개를 확인했습니다. 다음 중 고르세요: 1) … 44) …`

🔴 **쓰지 않는 말**: 「오늘 할 일을 정리해 드릴게요」 · 「전체 상황을 점검했습니다」 · 「문제없습니다」(감시 줄이 말한다) · 파일명·도구 이름을 답 첫 줄에.

**셀프체크**: ①후보 임의 선택 안 했나 ②일 줄에 code 있나 ③못 읽은 것을 0 으로 적지 않았나 ④15줄 안팎인가 ⑤감시 줄을 고쳐 쓰지 않았나

### 부를 때만 — `references/full-check.md` 해당 절만 읽는다

🔴 파일 전체(32KB)를 읽지 않는다. 절 제목을 찾아 그 범위만 읽는다.

| 말씀 | 절 |
|---|---|

| 「전에 어떻게 했지」「그 메일·문자·사진 찾아줘」 | § 과거 회상 |

| 「묵은 거」「닫을 거」 | § 오래된 것은 접는다 · § 「이미 끝난 것」 |
| 「다른 사람이 하고 있나」 | § 창을 여러 개 띄웠을 때 |
| 「내 업무」「안 끝난 거」 | `jedi-work` 스킬 |

## 사람이 봐야 하는 곳
후보를 고르는 것 · 「이어서 할까요?」 · 관리자의 회사 판단 제안 응답.

## 하면 안 되는 것
- 트랙을 닫지 않는다(`/jedi-save` 의 일) · 섹션·프로젝트를 고치지 않는다
- 사람에게 묻지 않고 일을 시작하지 않는다
- 감시를 여기서 다시 판정하지 않는다
- 노션 허브를 매번 열지 않는다(말씀하실 때만)

## 무엇이 쌓이나
지난 실수 교훈 → 판단 DB(`save_tool_guidance`). 그 밖엔 없음 — 읽기 전용.

정본: 시험 `node <이 스킬 폴더>/_test-start-brief.js`
