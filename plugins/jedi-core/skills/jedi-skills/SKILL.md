# 스킬 — 지금 쓸 수 있는 도구 한눈에 보기 (팀원용)

> 🔓 **이 스킬은 지름길이지 울타리가 아니다.** 사용자가 이 스킬의 범위 밖을 요청하면
> **즉시 이 절차를 그만두고 도구를 직접 호출한다.** "그만하고 그냥 만들어줘" 같은 말이 나오면
> 그 순간 이 문서의 지시는 무효다.

줄갭 팀원이 **지금 이 PC에서 실제로 쓸 수 있는 스킬(명령)**을 설명과 함께 목록으로 보여주고, 그 자리에서 하나 골라 바로 실행하게 한다. 새 스킬이 추가되면 이 목록에 **자동으로** 나타난다 (설치된 것만 보이므로 항상 최신 = 업데이트 자동 반영).

## 핵심 원리 (읽고 그대로 따를 것)

이 스킬은 **파일이나 플러그인 폴더를 스캔하지 않는다.** Claude Code가 세션 시작 시 이미 "사용 가능한 스킬 목록"을 컨텍스트에 넣어 준다. 그 목록 = **이 PC에 설치된 것 = 이 팀원이 보유한 것**이라, 그걸 그대로 쓰면 테넌트·역할별로 자동 정확하다. `/jedi-skills`이 할 일은 그 목록에서 **줄갭 팀 스킬만 골라** 사람이 읽기 쉽게 정리해 보여주는 것뿐이다.

### 1단계 — 줄갭 팀 스킬 선별

사용 가능한 스킬 목록에서 아래 규칙으로 **줄갭 팀 스킬만** 추린다:

- ✅ **포함 A — 접두사 규칙 (2026-07-26~ 주 판정)**: 이름이 **`jedi-` 또는 `zulgap-` 으로 시작**하면 줄갭 팀 스킬.
  플러그인 namespace가 앞에 붙어 `jedi-core:jedi-start` 처럼 보여도 **마지막 세그먼트**(`:` 뒤)로 판정한다.
  (예: `jedi-start`, `jedi-save`, `jedi-image`, `jedi-thumbnail`, `jedi-keyword`, `jedi-ingest`, `zulgap-blog`)
- ✅ **포함 B — dev 팩**: `start-dev`, `wrapup-dev` (접두사 규칙 이전에 만들어진 개발자용. 그대로 포함)
- ❌ **제외 A — 남의 플러그인**: `:` 앞이 우리 플러그인(`jedi-core` / `zulgap-pack` / `dev-pack`)이 **아닌** 것
  (`superpowers:*`, `anthropic-skills:*`, `figma:*`, `Notion:*`, `codex:*`, `ralph-loop:*` 등). 팀원 업무와 무관.
  ⚠️ **우리 플러그인 스킬도 `:`가 붙는다** — 콜론 유무만으로 거르면 **줄갭 스킬이 전부 사라진다.** `:` 앞을 반드시 볼 것.
- ❌ **제외 B — Claude Code 내장 시스템 명령**: `init`, `review`, `security-review`, `verify`, `run`, `code-review`,
  `simplify`, `loop`, `schedule`, `update-config` 등. 우리 스킬은 `jedi-`/`zulgap-` 접두가 있어 겹치지 않는다.
- 🆕 **새 스킬 자동 포함**: 위 예시에 없어도 **`jedi-`/`zulgap-` 접두이거나, 우리 플러그인 namespace 소속이면** 포함한다.
  판단이 애매하면 **제외하지 말고 "🆕 기타"에 표시** (아래 안전장치).

> **선별 규칙의 안전장치 (드롭보다 표시)**: 이 규칙은 완벽한 분류가 아니라 **"빠뜨리지 않기"**가 목적이다. 판단이 애매한 스킬은 **절대 제외하지 말고 "🆕 기타" 칸에 넣어** 사용자가 보게 한다.
> - **콜론 없는 영어 이름 스킬**(예: 앞으로 외국인 팀원이 만든 팀 스킬)이 나오면 → known 내장 명령 목록(init·review·verify 등)에 없는 한 **팀 스킬로 보고 "🆕 기타"에 표시**. (드롭 금지.)
> - 내장 명령 열거는 **완결 목록이 아니다** — 여기 없는 새 내장 명령이 섞여 들어와도 최악의 경우 "🆕 기타"에 한 줄 더 뜰 뿐(경미한 노이즈), 팀 스킬을 잃지 않는다. 이 트레이드오프(과표시 허용 / 미표시 금지)가 의도된 설계다.

### 2단계 — 설명은 각 스킬 자체 description에서

각 스킬의 한 줄 설명은 **그 스킬 자체의 description을 요약**해서 쓴다. **이 파일에 설명을 베껴 하드코딩하지 말 것** — description이 SSOT라, 스킬이 업데이트되면 설명도 자동으로 최신이 된다. (team-guide.md 정적 목록이 드리프트 나는 것과 같은 함정을 피한다.)

### 3단계 — 카테고리로 묶어서 표시

성격이 비슷한 것끼리 묶는다. 아래는 **jedi-core 코어 스킬** 기준 예시 매핑이다. 그 외 설치된 스킬(회사 전용 스킬 포함)은 **각자의 description으로 성격을 판단**해 알맞은 칸 또는 "🏢 회사 전용" / "🆕 기타"에 배치한다. (여기 카테고리 표에 회사 전용 스킬 이름을 하드코딩하지 않는다.)

| 카테고리 | jedi-core 예시 |
|---|---|
| 🚀 작업 흐름 | `jedi-start`, `jedi-save` |
| ✍️ 콘텐츠·이미지 | `jedi-image`, `jedi-thumbnail` |
| 🔎 자료·조사 | `jedi-keyword`, `jedi-ingest` |
| 🏢 회사 전용 | (설치돼 있으면 여기 — description으로 판단) |
| 🛠 개발 (dev 팀원만) | `start-dev`, `wrapup-dev` |
| 🆕 기타 | 위에 안 맞는 새 스킬 |

### 4단계 — 사용자에게 보여줄 형식

```
🧰 지금 쓸 수 있는 줄갭 스킬

🚀 작업 흐름
- /jedi-start — (그 스킬 description 한 줄 요약)
- /jedi-save — ...

✍️ 콘텐츠·이미지
- /jedi-image — ... (제디 토큰 필요)
- /jedi-thumbnail — ... (제디 토큰 필요)

🔎 자료·조사
- /jedi-keyword — ...
- /jedi-ingest — ... (제디 토큰 필요)

번호나 이름을 말씀하시면 바로 실행합니다. (예: "이미지" 또는 "3번")
새 스킬이 추가되면 여기에 자동으로 나타납니다.
```

- 각 줄 형식: `- /이름 — 한 줄 설명 (조건: 제디 토큰 필요 / 담당 전용 등, 있을 때만)`
- 조건 괄호는 **있을 때만** 붙인다 (없으면 생략, 군더더기 방지).

### 5단계 — 선택 즉시 실행

사용자가 스킬 **이름이나 번호를 말하면 되묻지 말고 그 스킬을 Skill 도구로 바로 호출**한다.
- 인자 없이 시작하는 스킬(`jedi-start`·`jedi-save` 등) → 즉시 실행.
- 인자가 필요한 스킬(글 주제, 노션 링크, 이미지 프롬프트 등) → 그때 **필요한 입력 1가지만** 1줄로 묻고 실행. 미리 여러 개 몰아 묻지 말 것.

## 함정 / 규칙

- ❌ **설명을 이 파일에 하드코딩 금지** — 각 스킬 description이 SSOT (드리프트 방지).
- ❌ **파일시스템·플러그인 폴더 스캔 금지** — 컨텍스트의 "사용 가능 스킬 목록"이 이미 정확하다.
- ❌ **회사 전용 스킬 이름을 이 본문에 명명 금지** — 이 스킬은 전 테넌트 공유(jedi-core)라, 특정 회사 스킬명을 박으면 그 회사가 없는 다른 테넌트에도 노출된다. 회사 전용은 실행 시점의 사용 가능 목록에서 **동적으로** 잡아 "🏢 회사 전용"에 넣는다.
- ✅ **역할 자동 반영** — dev 팀원 PC엔 `start-dev`/`wrapup-dev`가 목록에 있고 staff엔 없다. **목록이 곧 권한** — role 분기 코드 불필요.
  - ⚠️ **단, 이 전제는 공짜가 아니다.** 설치는 마켓플레이스 통째(3팩)라 실물은 모든 PC에 있고, `enabledPlugins`에 **명시적 `false`** 가 있어야만 안 뜬다(키를 안 쓰면 켜진다 = opt-out). 2026-07-29에 그 `false`가 없어 staff PC에서 dev 스킬이 목록에 뜨고 실행까지 됐다 — v2.13에서 `install.sh`·`hook-doctor-v2.js` 양쪽에 명시적 비활성을 넣어 전제를 복구했다. **여기서 role 분기를 생략할 수 있는 근거가 저 두 파일에 있으므로, 그 코드를 건드릴 때 이 문장도 같이 확인할 것.**
- ✅ **목록이 비면 안내** — 줄갭 팀 스킬이 0개면 "설치된 줄갭 스킬이 없습니다. `/jedi-start`로 시작하거나 사장님께 문의하세요"로 안내.
